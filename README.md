# Erodotos.github.io

Personal website of Erodotos Demetriou, served by GitHub Pages.

Plain HTML and CSS, no build step:

- `index.html`: landing page
- `cv.html`: CV (the PDF download is `assets/Erodotos Demetriou CV.pdf`)
- `publications.html`, `talks.html`: publications and talks
- `css/style.css`: shared styles, with light and dark themes
- `js/theme.js`: theme switch (follows the system setting until the visitor picks one)

To add a talk, copy the commented example block in `talks.html`.
