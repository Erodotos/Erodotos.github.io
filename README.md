# Erodotos.github.io

Personal website of Erodotos Demetriou, served by GitHub Pages.

Plain HTML and CSS, no build step:

- `index.html`: landing page
- `cv.html`: CV (the PDF download is `assets/Erodotos Demetriou CV.pdf`)
- `publications.html`, `engagements.html`: publications, talks and hackathons
- `css/style.css`: shared styles

To add a talk, copy the commented example block in `engagements.html`.
