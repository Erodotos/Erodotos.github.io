WHAT IT CATCHES
LAYER 1
Gateway
Outer layer · every platform
  • Prompt-injection and jailbreak patterns
  • PII and secrets in prompts and answers
  • Tool calls the agent isn't allowed to make: the $5,000 payment
LAYER 2
Agent
Your code and instructions
  • Requests outside the agent's task
  • Wrong or unsafe output before it acts (amounts, formats, recipients)
  • Tools it doesn't need, never wired in
LAYER 3
Model
The provider's built-in safety
  • Harmful and toxic content
  • Known jailbreak techniques
Each layer catches what the others miss.
